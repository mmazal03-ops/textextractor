# Textract - Quick OCR & PDF Extractor

A lightweight tool to extract text from PDF files and images using Python, with built-in support for both English and Hebrew, and automatic `.txt` file saving.

## Features
- Extracts text from PDFs (page by page) and images (`.png`, `.jpg`, `.jpeg`).
- Supports bulk folder processing.
- Automatically saves the extracted text into a clean `.txt` file.

## Requirements
- Python 3.x
- Libraries: `pytesseract`, `PIL`, `pdf2image`
